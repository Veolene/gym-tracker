Guide

How the program works

Jeff Nippard's Essentials program: 12 weeks, 5 sessions a week (Upper, Lower, Push, Pull, Legs). The weeks come in 3 blocks of 4 — the exercises stay the same within a block and change when a new block starts.

Progress every week: beat last week by adding a little weight (1–2.5 kg) or 1–2 reps on the same exercise, with the same clean form. The app shows what you did last time on every set so you always know the number to beat.

Intensity & techniques

RPE
Rate of perceived exertion — how hard the set should feel. RPE 10 = true failure, 9 = one more rep was possible, 8 = two more, 7 = three more.
Dropset
On the last set only: finish your reps, immediately drop the weight by about half, and do the same number of reps again. Log the main part of the set.
A1 / A2
Superset — alternate the two exercises: a set of A1, straight into a set of A2, then rest. Repeat for each round.
Top set
A heavy, low-rep set to build strength. Warm up properly first.
Back-off
A lighter set after the top set with more reps — focus on the stretch and squeeze.
Failure
As many good reps as possible; stop when your form breaks.

Warm-up

About 5–10 minutes before every session. Tick things off as you go — the list resets each day.

Warm-up sets before heavy work

Each exercise lists how many warm-up sets to do. Use your planned working weight:

  • 50%× 10 easy reps to get blood flowing
  • 70%× 6 reps to groove the movement
  • 85%× 3 reps to prime for the heavy set

One warm-up set: do the 70% set. Two: 50% and 75%. The exercise screen works out the weights for you.

Recovery

  • Protein: 1.6–2.2 g per kg of bodyweight a day.
  • Sleep: 7–9 hours — this is when you actually grow.
  • Water: 3–4 litres a day, more when it's hot.
  • Rest timer: starts by itself after each set — heavy compound sets need the full rest.

Signs you need a deload

  • Strength going down for 2+ weeks
  • Constant fatigue, poor sleep
  • Joint pain or nagging aches
